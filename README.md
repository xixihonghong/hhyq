# 你在《后会友期》里是谁 · 友情人格测试

一个纯静态的 H5 小测试：32 道五点量表题，测出你在友情里最像《后会友期》的哪一位嘉宾，
结果页给出四维坐标、卡点、处方、节目里的旧友搭档，以及一张可保存的结果海报。

> 非官方同人作品，与节目组、嘉宾本人无关。结果仅供娱乐与自我了解，不构成任何心理诊断。

## 直接打开

双击 `index.html` 即可（不需要服务器、不需要联网、没有构建步骤）。

想用本地服务器也可以：

```powershell
cd "D:\桌面\文件夹\chengxu\后会有期问卷"
python -m http.server 8080
# 打开 http://127.0.0.1:8080
```

手机上想看，把整个文件夹拷到手机或用同一局域网的服务器地址即可（布局按移动端优先设计，桌面端是居中的手机列）。

## 发布到 GitHub Pages（公网链接）

仓库已初始化（分支 `main`），只差你创建远程仓库后推一次：

```powershell
# 先在 https://github.com/new 建一个空的 Public 仓库（名字随意，示例用 hhyq）
.\deploy.ps1 -User 你的GitHub用户名
```

脚本会自动配置 `origin`、推送 `main`，并在最后打印 Pages 设置步骤。也可以按 `DEPLOY.md` 手动执行。

## 目录结构

```
index.html            三个屏幕：首页 / 答题 / 结果 + 两个抽屉（全部人格、海报）
css/style.css         全部样式（奶油色卡片、五点量表、四维条、海报面板）
js/data.js            数据层：4 条轴、8 位嘉宾画像、32 道题
js/assets.js          8 张头像的 base64 内联（自动生成，勿手改）
js/app.js             交互层：答题流程、计分匹配、结果渲染、海报绘制
assets/img/*.jpg      8 张嘉宾头像（720×900，统一暖调 + 颗粒 + 暗角）
shots/                开发期截图与 CDP 截图脚本（shot.mjs）
tools/                抓图 / 裁图脚本（Python，含来源 meta）
```

## 玩法与规则

- **四条轴**（0–100，0 为左极）：
  1. 表达：藏心里 ↔ 说出口
  2. 修复：转身走 ↔ 追着问
  3. 距离：各自安好 ↔ 想黏着
  4. 判断：讲感受 ↔ 讲事实
- 每题 1–5 分，换算成 0/25/50/75/100，按轴取平均。
- 与 8 位嘉宾的画像做**加权平均绝对差**（修复轴权重 1.1，其余 1.0），
  距离越小越像；匹配度 = `clamp(102 − 距离 × 0.95, 55, 99)`。
- 结果页的"最容易和你走散的人"取距离最远的一位，理由由差异最大的两条轴生成。

## 可改的地方

- 换题：`js/data.js` 里的 `QUESTIONS`（`axis` 0–3，`l`/`r` 是两端的标签）。
- 改画像：`GUESTS` 里每位嘉宾的 `type`/`tagline`/`quote`/`story`/`stuck`/`rx`/`scores`。
  名字与短句会直接进结果页和海报。
- 配色：`css/style.css` 顶部 `:root` 的一组变量。
- 想看某个结果的完整样子：`index.html?g=xufei`（画像预览），
  `index.html?g=xufei&s=88,86,88,26`（带分数，四维条会按这组数渲染）。

## 图片为什么是内联的

`js/assets.js` 把 8 张头像写成 data URI 内嵌进页面，所以：

- 不依赖相对路径，双击打开、被其它程序预览、只拷 html 都不会裂图；
- 结果页「保存图片」用 canvas 导出时不会被 file:// 的同源策略挡住（外链图片会污染 canvas，导出会失败）。

改完 `assets/img/` 里的图之后运行一次：

```powershell
python tools/gen_assets_js.py
```

## 只做了前端

没有后端、没有埋点、没有第三方脚本；答题进度存在 `localStorage`（键 `hhyq-quiz-v1`），
刷新后可以接着答，"重新测一次"会清掉。

## 素材说明

头像来自公开报道与节目物料（广州日报新花城、网易号、Bing 图片搜索等），
经裁切与统一调色用于人物识别，版权归原作者所有；如用于正式发布请替换为授权图片。
其中白小纯一图源图分辨率较低，已用统一颗粒/暗角处理，放大后略软。

## 开发备注

- 中文参数不要直接经 PowerShell 传给 Python（会被转成 GBK），
  抓图脚本统一读 UTF-8 的 manifest。
- 用 Chrome headless 直接 `--screenshot --window-size=390,844` 截不出真实的移动端视口
  （窗口最小宽度是 512），必须走 CDP：`node shots/shot.mjs <url> <out.png> [宽] [高] [注入脚本] [延迟ms]`。
